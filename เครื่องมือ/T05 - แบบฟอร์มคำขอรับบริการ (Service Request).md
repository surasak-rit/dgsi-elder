# 🛎️ แบบฟอร์มคำขอรับบริการศูนย์ฯ (Service Request)

> เครื่องมือ T05 ในชุด [[09 - เครื่องมือดำเนินงาน (Operations Toolkit)]] — ช่องทางรับคำขอตาม Service Model ใน [[04 - แคตตาล็อกงานและบริการ]]

> [!info] ใช้เมื่อใด
> หน่วยงาน/บุคลากรต้องการขอรับบริการใด ๆ จากศูนย์ฯ (ดูรายการ SVC-01 ถึง SVC-09) — คัดลอกฟอร์มนี้เป็นรายการใหม่ต่อ 1 คำขอ

## 3. การคัดกรองและมอบหมาย (สำหรับศูนย์ฯ)

| รายการ | รายละเอียด |
|--------|-----------|
| รับเรื่องโดย | _____________ |
| Tier บริการ | ⬜ Tier 1 บริการตนเอง ⬜ Tier 2 ให้คำปรึกษา ⬜ Tier 3 พัฒนาร่วม |
| มีข้อมูลส่วนบุคคล? | ⬜ ใช่ → ต้องทำ [[T02 - แบบประเมินผลกระทบความเป็นส่วนตัว (DPIA)\|DPIA]] ⬜ ไม่ |
| เป็นโครงการ AI? | ⬜ ใช่ → ต้องทำ [[T06 - แบบกลั่นกรองจริยธรรม AI (AI Ethics Review)\|AI Ethics Review]] ⬜ ไม่ |
| ขอเข้าถึงข้อมูล? | ⬜ ใช่ → ใช้ [[T07 - แบบฟอร์มคำขอเข้าถึงข้อมูล (Data Access Request)\|Data Access Request]] ⬜ ไม่ |
| ผู้รับผิดชอบ/ฝ่าย | _____________ |
| สถานะ | ⬜ รับเรื่อง ⬜ กำลังดำเนินการ ⬜ เสร็จสิ้น ⬜ ปฏิเสธ |

> [!example] SLA อ้างอิง
> ตอบรับภายใน 2 วันทำการ · คำขอข้อมูลมาตรฐาน 5 วันทำการ · DPIA 10 วันทำการ

> [!warning] บริการบนข้อมูลอ่อนไหว
> SVC-06 และ SVC-09 ต้องผ่าน DPIA และอนุมัติจาก Data Owner ก่อนเสมอ (ดู [[04 - แคตตาล็อกงานและบริการ]])
