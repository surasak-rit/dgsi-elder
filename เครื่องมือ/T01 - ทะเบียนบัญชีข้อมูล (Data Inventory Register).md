# 🗃️ ทะเบียนบัญชีข้อมูล (Data Inventory Register)

> เครื่องมือ T01 ในชุด [[09 - เครื่องมือดำเนินงาน (Operations Toolkit)]] — ลงมือทำตามแผน [[08 - แผนการจัดทำ Data Inventory]] (โดยเฉพาะ P2 จัดทำบัญชี)

> [!info] วัตถุประสงค์
> ทะเบียนกลางบันทึกว่า "องค์กรมีข้อมูลอะไร อยู่ที่ไหน ใครเป็นเจ้าของ ชั้นความลับใด ใช้ทำอะไร" — เป็นแหล่งอ้างอิงเดียว (Single Source of Truth) ของงานธรรมาภิบาลข้อมูลทั้งหมด

---

## ✅ เกณฑ์ความครบถ้วนก่อนปิดรายการ

- [ ] ฟิลด์บังคับ (✅) ครบทุกช่อง
- [ ] มี Owner / Steward / Custodian ครบ (Ownership = 100%)
- [ ] รายการที่ "มีข้อมูลส่วนบุคคล = ใช่" เชื่อม [[T03 - ทะเบียนกิจกรรมการประมวลผลข้อมูล (RoPA)|RoPA]] แล้ว
- [ ] รายการชั้น Confidential/Restricted ที่เสี่ยงสูง ส่งเข้า [[T02 - แบบประเมินผลกระทบความเป็นส่วนตัว (DPIA)|DPIA]]
- [ ] ผ่านการรับรองโดย Data Owner (P4 ใน [[08 - แผนการจัดทำ Data Inventory]])

> [!warning] เฝ้าระวัง Shadow Data
> อย่าลืมสำรวจสเปรดชีต/คลาวด์ส่วนตัวที่เก็บข้อมูลส่วนบุคคล — เป็นจุดเสี่ยง `#standard/pdpa` สูงสุด ต้องขึ้นทะเบียนด้วย

> [!tip] ทำให้เป็นปัจจุบัน
> ตั้งรอบทบทวนทุก ≤ 90 วัน (ตัวชี้วัด Freshness) — รายการที่ "ทบทวนล่าสุด" เกินกำหนดให้รายงานใน [[T09 - แดชบอร์ดติดตาม KPI (KPI Tracker)|KPI Tracker]]
