# 00 — คำถามสำคัญสำหรับผู้ใช้งาน Performance Report
> ชุดคำถามเก็บความต้องการ (Requirements Elicitation) ก่อนออกแบบรายงานและ Data Model
> ที่มา: เอกสาร `Performance Report Requirements.doc` + ไฟล์ `การคำนวณสัดส่วนลงทุน.xlsx` (sheet Raw) จาก Google Drive ของศูนย์บริหารสินทรัพย์ (AMC)

---

## วิธีใช้เอกสารนี้
- ใช้เป็น **แบบสัมภาษณ์/แบบสำรวจ** กับผู้ใช้งานจริง (ผู้บริหารกองทุน, เจ้าของส่วนงาน, ทีมบัญชี/การเงิน, ทีมข้อมูล)
- แต่ละหัวข้อมี **คำถามหลัก** + **ทำไมต้องถาม (เชื่อมกับ Data Model)** เพื่อให้คำตอบนำไปออกแบบโครงสร้างข้อมูลได้ทันที
- ช่อง "ค่าเริ่มต้นที่พบในสเปก" = สิ่งที่ดึงได้จากเอกสารแล้ว ใช้เป็น default ถ้าไม่มีคำตอบเพิ่มเติม

| A4 | ผู้ใช้ดูบนอุปกรณ์อะไรเป็นหลัก (เดสก์ท็อป/มือถือ/พิมพ์เป็น PDF)? | กำหนด responsive และรูปแบบ export |

## C. ตัวชี้วัดผลการดำเนินงาน (Performance Metrics)

| # | คำถาม | ค่าเริ่มต้นที่พบในสเปก |
|---|-------|----------------------|
| C1 | ตัวชี้วัดที่ต้องแสดงมีอะไรบ้าง? | Portfolio return %, Benchmark (BM) return %, ความผันผวนกอง (SD), ความผันผวน BM |
| C2 | ช่วงเวลาที่ต้องแสดงแบบ "ปักหมุด" (point-to-point) มีอะไรบ้าง? | 1M, 3M, 6M, 1Y, 3Y, 5Y, 10Y, since inception |
| C3 | ช่วงเวลาที่ต้องแสดงแบบ "ตามช่วงเวลา" (period) มีอะไรบ้าง? | รายเดือน, ไตรมาส, ปีปฏิทิน, ปีงบประมาณ (FY) |
| C4 | วิธีคำนวณ return ใช้ NAV/unit ใช่ไหม และ "ลดหน่วยลงทุนตอนจ่ายปันผล" (ไม่ rebase ปันผล) ใช่ไหม? | ใช่ — ศูนย์ใช้วิธีลดหน่วยลงทุน จึงไม่นำปันผลต่อหน่วยมาคิด return |
| C5 | สูตร annualize: รายวันกับรายเดือนใช้สูตรเดียวกันใช่ไหม? และ SD annualized = SD × √12 ใช่ไหม? | ใช่ทั้งคู่ |
| C6 | ความละเอียดทศนิยม: เก็บ 6 ตำแหน่ง แสดง 2 ตำแหน่ง ใช่ไหม? ใช้กับทุกตัวชี้วัดไหม? | ใช่ (return และ BM) |
| C7 | BM ต้อง rebase ที่ NAV/unit since inception = 10 บาท แล้วสร้าง index ใหม่ ใช่ไหม? | ใช่ — `10 × (1 + return%)` |
| C8 | BM มีเฉพาะรายเดือนใช่ไหม (ไม่มีรายวัน)? แล้วถ้าผู้ใช้เลือกช่วงรายวันจะแสดง BM อย่างไร? | BM return และ BM volatility มีเฉพาะรายเดือน |
| C9 | ต้องการตัวชี้วัดเพิ่มไหม (Sharpe, tracking error, max drawdown, active return)? | — (ต้องถาม / อาจเป็น phase 2) |

## ✅ 12 คำถาม "ต้องได้คำตอบก่อนเริ่ม" (Top Priority)
1. ผู้ใช้หลักคือใคร และคำถามอันดับ 1 ที่ต้องตอบทันทีคืออะไร? (A1, A2)
2. สิทธิ์ผูกกับ email → เห็นกองระดับไหน (กอง/ส่วนงาน/ประเภท)? (B1)
3. ต้องเห็นทั้งกองเดี่ยวและกองรวม + แยกหมุนเวียน/ไม่หมุนเวียนไหม? (B2, B3)
4. ตัวชี้วัดครบชุดที่ต้องมี และมีตัวเพิ่มจากสเปกไหม? (C1, C9)
5. ยืนยันวิธีคำนวณ return (NAV/unit, ไม่ rebase ปันผล) และ annualize? (C4, C5)
6. ระดับ drill-down ของ allocation ลึกถึงรายหลักทรัพย์หรือหยุดที่กลุ่ม? (D3)
7. มิติที่ต้องการของ holdings (สกุลเงิน/rating/issuer/duration)? (D4)
8. ความถี่อัปเดตและวิธีนำเข้า (manual/automated)? (F1, F4)
9. ต้อง export อะไร และสองภาษาไหม? (G3, G4)
10. แหล่งความจริงของตัวเลข และต้อง maker-checker ไหม? (H1, H3)
11. กฎ mapping Client Code ระหว่าง Raw กับตารางแม่? (H5)
12. ต้องเชื่อม Data Catalog/ทำ lineage + audit log PDPA ไหม? (I2, I4)
