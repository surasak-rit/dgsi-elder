## 1. หลักการที่ใช้ (อ้างอิงเอกสาร 03)
| หลักการ | ที่มา | นำมาใช้อย่างไร |
|---------|-------|----------------|
| **Overview first, zoom & filter, details on demand** | Shneiderman 1996 | แท็บ 00 = ภาพรวม → แท็บ 01–05 = เจาะลึก |
| **SUCCESS / notation เดียวกันทุกหน้า** | IBCS / ISO 24896 | สีเดียวกัน = ความหมายเดียวกันทุกหน้า (navy=กองทุน, gold=ดัชนี) |

## 2. โครงเรื่อง (Narrative Arc) — เล่าเป็น 6 องก์
รายงานนี้ออกแบบให้ "อ่านเป็นเรื่องเล่า" ไล่จากคำถามใหญ่ → คำตอบเชิงลึก:

| แท็บ | คำถามที่ผู้ใช้ถามในใจ | คำตอบ (พาดหัวเรื่องเล่า) |
|------|----------------------|--------------------------|
| **00 ภาพรวม** | "เงินฉันเป็นยังไงบ้าง?" | พอร์ต 5,183 ลบ. โต +124.9% ตั้งแต่ตั้งกอง ชนะดัชนี เสี่ยงต่ำ |
| **01 ปักหมุด** | "ได้เท่าไร เทียบดัชนีชนะไหม?" | ชนะดัชนีในกรอบสั้น-กลาง ด้วยความผันผวนต่ำกว่า |
| **02 ตามช่วงเวลา** | "แต่ละปีเป็นยังไง?" | บวกทุกปีงบฯ เร่งตัวขึ้น FY2567 +6.72% |
| **03 กราฟ NAV** | "เติบโตมายังไง?" | 10 → 22.49 บาท ราบเรียบ ไม่มีดิ่งแรง |
| **04 เคลื่อนไหว** | "มีเงินเข้า-ออกอะไรบ้าง?" | แกว่งแคบ มีเพิ่ม/ลดทุนตามปกติ |
| **05 สัดส่วน** | "เงินไปอยู่ที่ไหน?" | 84.9% ตราสารหนี้มั่นคง + กระจายความเสี่ยง |

> **กุญแจของ storytelling:** แต่ละหน้ามี **กล่อง "เรื่องเล่า" (story callout)** สีทอง อธิบายว่าตัวเลข "หมายความว่าอะไร" ไม่ใช่แค่โชว์ตัวเลขลอยๆ — เปลี่ยนจาก *reporting* เป็น *insight*

## 3. ภาษาภาพ (Visual Language)
- **อารมณ์:** Private Banking / สถาบันการเงินระดับพรีเมียม — น่าเชื่อถือ สุขุม
- **สี (Mahidol identity):** น้ำเงินเข้ม `#16314f` (กองทุน) · ทอง `#b8893b` (ดัชนี/เน้น) · พื้นงาช้าง · teal/terracotta/slate สำหรับกลุ่มสินทรัพย์
- **ฟอนต์:** Trirong (serif หัวเรื่อง — สง่า) + IBM Plex Sans Thai (เนื้อหา) + IBM Plex Mono (ตัวเลขการเงิน เรียงหลักตรง)
- **กฎสีคงที่ (IBCS):** navy = กองทุนเสมอ, gold = ดัชนีเสมอ — ผู้ใช้จำได้ทุกหน้า เปรียบเทียบข้ามหน้าได้ทันที

## 4. องค์ประกอบที่เชื่อมกับ Data Model (เอกสาร 01)
| ส่วนบน Dashboard | ดึงจาก Fact/Dim |
|-------------------|------------------|
| KPI: NAV, NAV/หน่วย, เงินเข้า-ออก | `FactNAV` |
| ตารางปักหมุด + กราฟ FY + ความผันผวน | `FactReturn` |
| กราฟเส้น NAV | `FactNAV` (time series) |
| โดนัท + ตารางเจาะลึกกลุ่ม | `FactHolding` → `DimAssetClass` |
| Dropdown เลือกกอง (ตามสิทธิ์) | `DimFund` + RBAC (email→fund) |
| "ณ วันที่" | `DimDate` |

## 5. ฟีเจอร์ในต้นแบบ (คลิกได้จริง)
- ✅ แท็บนำทาง 6 หน้า (สลับได้)
- ✅ ปุ่ม toggle (NAV/หน่วย ↔ บาท, ปีงบฯ ↔ ไตรมาส) — เชิงสาธิต
- ✅ Dropdown เลือกกองตามสิทธิ์
- ✅ กราฟ SVG ทำมือ (โดนัท/เส้น/แท่ง) ใช้ข้อมูลจริง
- ✅ responsive (จอเล็กยุบเป็นคอลัมน์เดียว)

## 6. ข้อเสนอเพิ่มเติม (Phase 2)
1. **Drill-through รายหลักทรัพย์** จากกลุ่มในหน้า 5 → ตาราง ISIN/issuer/rating/duration (มีข้อมูลใน Raw แล้ว)
2. **เพิ่มตัวชี้วัด GIPS-recommended**: Sharpe / Tracking Error / Max Drawdown (เอกสาร 03)
3. **Export PDF ทางการ** (ตรามหาวิทยาลัย + ณ วันที่ + แหล่งข้อมูล)
4. **Alert** กองที่ต่ำกว่าดัชนี (เน้นสีในหน้า Overview)
5. **2 ภาษา** (ไทย/อังกฤษ) ตาม path `/en`
